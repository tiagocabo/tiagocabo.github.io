Experiment tracking with MLflow

With MLflow tracking you can organize all your ML project experiments in one single platform. The full code is in the GitHub repo.

MLflow is an open source tool backed by Databricks. It works with several languages such as R, Python and Java. It was designed to be multi-user and integrates easily with Apache Spark. It has 3 main blocks:

  • MLflow Tracking
  • MLflow Projects
  • MLflow Models

MLflow Projects is a tool to reproduce experiment runs, and MLflow Models is a file format to deploy the models. From now on I will only focus on MLflow Tracking.

Step 1: setup and UI

Install MLflow, go to your chosen directory in the console and run mlflow ui.

pip install mlflow
mlflow ui

Step 2: run the first experiment

MLflow provides some methods to configure the MLflow session:

  • mlflow.set_tracking_uri('http://xx.xx.x.xx:5000') is very useful when the MLflow server runs on another machine. I recommend this, so your colleagues can access your results.
  • mlflow.set_experiment("Elastic Net") creates sections, so you can better organize your experiments.
  • mlflow.start_run('name') starts a new run. You can also give it a name.
  • mlflow.set_tag("mlflow.note.content", "Grid search") adds notes to your runs. This helps you keep track of small details of an experiment that aren't expressed in the metrics, parameters or artifacts.

After adding these blocks you should get a similar structure:

MLflow has 3 main ways to track information:

  • mlflow.log_params('name', object, step)
  • mlflow.log_metrics('name', object, step)
  • mlflow.log_artifacts('name', object, step)

Once your metrics are logged you can plot and compare them across models, which helps you choose the best one.

Tips

If your problem uses epochs, I advise you to use the step parameter, because it allows a better comparison between epochs. The same works for k-fold validation.

import mlflow
mlflow.log_metrics('name', variable, step)

To sum up

MLflow is in active development and has great features. I use MLflow Tracking daily. I found this tool when I started to have a lot of experiments and felt lost among all the notebooks.
